You are a senior full-stack developer and design system architect.

Enhance the existing Template System to support **Design Variants per Template**, ensuring that the same data structure can be rendered in multiple visual styles.

---

# 🔹 GOAL

Each template should support:

* Same slide structure
* Same data mapping
* Multiple design/layout styles (like Gamma)

Example:
Template: "Quarterly Business Review"
Variants:

* Corporate Clean
* Visual Cards
* Minimal Executive
* Dark Mode
* Infographic Style

---

# 🔹 CORE CONCEPT

Separate:

1. DATA STRUCTURE (what to show)
2. DESIGN VARIANT (how to show)

---

# 🔹 DATA MODEL UPDATE

Update template model:

class PresentationTemplate {
string Id;
string Name;
string Category;
List<SlideDefinition> Slides;
List<DesignVariant> Variants;
}

class DesignVariant {
string Id;
string Name;
string Theme; // light, dark, colorful
string LayoutStyle; // grid, cards, infographic
StyleConfig Style;
}

class StyleConfig {
string FontFamily;
string PrimaryColor;
string SecondaryColor;
string Background;
string CardStyle;
string IconStyle;
}
